# Form & Function

A mobile-first, installable PWA for tracking posture, mobility, strength and daily self-care habits.

## Features
- Daily check-ins for activities, pain, energy, sleep and notes
- 12-week roadmap and weekly schedule
- Exercise library with technique cues and video-search links
- Progress summary and history
- Optional body measurements
- JSON export/import backup
- Offline shell with a service worker
- No account or server required. Data stays in browser localStorage.

## Deploy to GitHub Pages
1. In GitHub, open **Settings > Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then Save.
4. Open the published HTTPS URL on Android Chrome and choose **Install app** or **Add to Home screen**.

## Data and privacy
Entries remain in the browser profile on each device. There is no automatic sync. Export a JSON backup to move data to another device.

## Health note
This is a habit tracker, not a diagnostic or individualized rehabilitation tool. Given a history of ACL injury and concerns about knee alignment, obtain an in-person assessment before progressing loaded knee exercises. Stop for giving-way, locking, swelling, sharp pain, numbness or weakness. Exercise does not correct structural bone alignment.
